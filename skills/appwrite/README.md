# appwrite

![appwrite cover](./assets/readme-cover.png)

Reference skill for [Appwrite](https://appwrite.io/) — the open-source
backend-as-a-service providing Auth, Databases, Storage, Functions, Messaging,
and Realtime (self-hosted or Cloud). It steers an agent through the
backend-as-a-service model, permissions-as-data, the document database, serverless
functions, realtime subscriptions, and SDK integration, without relying on stale
version recall.

## Install

```bash
npx skills add hardgraph/skills --skill appwrite
```

## Use this skill for

- Adding auth, a document database, and file storage to an app
- Modelling data with attributes, relationships, indexes, and per-document permissions
- Running serverless Functions on events, schedules, or HTTP
- Sending push, SMS, and email through Appwrite Messaging
- Subscribing to live document and file changes with Appwrite Realtime
- Integrating the Web, Flutter, Apple, Android, or server SDKs

## What is included

- [`SKILL.md`](./SKILL.md) — the agent procedure and permissions guardrails.
- [`references/vendor/llms.txt/`](./references/vendor/llms.txt/) — a reproducible
  verbatim mirror of the Appwrite documentation the seed index links to, used for
  exact product, SDK, and API details.
